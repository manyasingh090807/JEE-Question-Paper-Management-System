# JEE-Question-Paper-Management-System
Python-based system to manage JEE questions and automatically generate practice question papers.
JEE Question Paper Management System

Project Overview

The JEE Question Paper Management System is a Python-based application developed as part of the Computational Thinking and Programming course.

The system helps users manage a question bank and automatically generate JEE-style practice question papers.

Objectives

* Maintain an organized question bank.
* Add, view, search, update and delete questions.
* Generate balanced question papers.
* Avoid unnecessary repetition of questions.
* Generate answer keys and summary reports.

Technologies Used

* Python
* CSV File Handling
* Random Module
* OS Module
* DateTime Module

Key Features

1. Question Bank Management
2. Question Search and Filtering
3. Question Updating and Deletion
4. Automatic Paper Generation
5. Answer Key Generation
6. Question History Management
7. Summary Report Generation

Project Structure

* main.py – Main application
* questions.csv – Question database
* history.csv – Previously used questions
* generated_papers/ – Generated output files

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run python main.py in the terminal.
